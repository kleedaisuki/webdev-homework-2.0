# W17 联通世界杯首页与两条用户旅程

日期：2026-11-20。对应 Issue：[W17 #32](https://github.com/kleedaisuki/webdev-homework-2.0/issues/32)。基线提交：`bf36e97`（`origin/main`）。

本文记录世界杯专题站访客端与管理员端两条主用户旅程的端到端可达性核对结果、后台导航接线补齐，以及交接给 W20（项目展示 PPT）、W21（助教演示脚本）和 W15（用户手册对账）的最终固定入口清单。

## 边界说明

- 本单按 Issue `#32` 要求，专做**访客端与管理员端的端到端可达性及前后台切换接线**，与 W09（`#26`）的首页赛果同步验收区分。
- 仅修改后台工作台及子页面的导航面包屑、公开页核对链接与窄屏表格滚动容器，不修改比赛比分/发布校验逻辑、不修改 SQL 或迁移、不改动已冻结的顶栏五栏导航与视觉布局。
- W15（用户手册，Issue `#31`）与 W16（个人作业归档，Issue `#14`）当前尚未合入；本单先锁定现有真实入口与标题，待 W15 出稿后直接对照下表核对入口名称，W16 合入后 `/downloads` 个人作业分区将自动列出归档 ZIP。

## 固定入口清单（交接 W15 / W20 / W21）

### 前台公开入口

| 实际路径 | 到达方式（无需手输 URL） | 页面标题（`<title>` 前缀） | 返回 / 下一步路径 |
| --- | --- | --- | --- |
| `/` | 顶栏「主页」或左上角「世界杯 2026」Logo | `2026 世界杯` | 走进世界杯、精选赛果详情、精彩进球、球迷讨论、认识我们的团队、成员卡片、项目分工 |
| `/world-cup`（别名 `/world-cup/matches`） | 顶栏「世界杯专题」、首页「走进世界杯」或「全部赛程与赛果 ↗」 | `赛程赛果` | 状态筛选（全部 / 未开赛 / 已完赛）、视图切换（时间表 / 小组对阵 / 淘汰赛）、单场「详情」、专题 Tab（精彩进球 / 球迷讨论） |
| `/world-cup/groups` | 赛程页「小组对阵」 | `小组对阵` | 赛程视图切换、单场详情、有演示数据时切换官方/演示 |
| `/world-cup/bracket` | 赛程页「淘汰赛」 | `淘汰赛晋级树` | 赛程视图切换、单场详情、有演示数据时切换官方/演示 |
| `/world-cup/matches/{id}` | 首页精选赛果卡片、赛程列表「详情」、小组/淘汰赛节点 | `{主队} vs {客队}` | `← 返回赛程赛果`、`探索精彩进球 →` |
| `/world-cup/highlights` | 首页「精彩进球」或专题 Tab「精彩进球」 | `精彩进球` | FIFA 官方视频外链、`球迷讨论 →` |
| `/world-cup/fans` | 首页「球迷讨论」或专题 Tab「球迷讨论」 | `球迷讨论` | `写留言 ↗`（进入 `/guestbook`） |
| `/guestbook` | 球迷讨论页「写留言 ↗」 | `留言` | 提交待审留言、浏览已通过留言、顶栏与专题 Tab 返回各栏目 |
| `/team` | 顶栏「团队成员」或首页「认识我们的团队 →」 | `我们的团队` | `团队与个人作业下载`、成员卡片「了解成员」、`查看项目分工 ↗`、顶栏「主页」/ Logo 返回 `/` |
| `/team/members/{id}` | 团队主页「了解成员」或首页底部成员卡片 | `{成员姓名}` | `返回我们的团队`、已实现成果链接、个人公开链接 |
| `/project` | 顶栏「项目经历」、首页「项目分工 ↗」或团队页「查看项目分工 ↗」 | `项目经历` | `浏览世界杯专题 ↗`、`认识团队成员 ↗`、成员成果链接 |
| `/downloads` | 顶栏「作业下载」或团队主页「团队与个人作业下载」 | `作业下载` | 下载 `/data/team/` 团队 PDF（当前已含需求文档）与 `/data/personal/` 个人 ZIP |

> 命名核对：顶栏入口标签为 `团队成员`，指向 `/team`（页面标题与首页分区均为「我们的团队」）；站点全程将课设成员与世界杯国家队分离，未将课设团队称作「参赛球队」。站内链接由路由首条规则默认生成 `/world-cup`，契约别名 `/world-cup/matches` 同样返回 200 且内容一致。

## 本次接线补齐文件

- `views/admin/index.php`：在三大管理入口下方补齐对称的「公开页核对」导航（世界杯首页、公开赛程与赛果、查看公开团队页、公开留言、作业下载）。
- `views/admin-fixture/index.php`、`views/admin-fixture/create.php`、`views/admin-fixture/update.php`：补齐后台面包屑与公开赛程/已发布公开详情核对入口，并给赛事列表表格包裹横向滚动容器（`.fx-table-wrap`），消除 390px 窄屏下的整页横向溢出。
- `views/admin-member/update.php`：将面包屑补全为 `管理工作台 / 团队资料 / 成员资料`，与赛事/审核子页统一。
- `views/admin-guestbook/index.php`、`views/admin-guestbook/retry.php`：补齐后台面包屑与「查看公开留言 ↗ / 查看球迷讨论 ↗」快捷入口及文件注释头。
- `web/css/portal.css`、`web/css/admin-fixture.css`：新增通用后台面包屑、公开页预览按钮、公开核对入口与表格滚动容器样式。
- `tests/w17-journeys.php`：新增端到端旅程回归脚本，全部跳转均从上一页真实 HTML `<a>` 链接提取，不手输目标 URL。
